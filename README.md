# UnichanceServer

API образовательного сервиса Unichance на Python и FastAPI. Включает авторизацию, пользователей с ролями, занятия и предметы, работу преподавателя и администратора, загрузку файлов и ИИ-помощника. Модели хранения реализованы на SQLAlchemy.

## Подготовка и запуск

```sh
python -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

Перед запуском настройте `core/config.py`: подключение к БД, ключ подписи токенов и ключи внешних сервисов. Настройки представлены объектом `Settings`, а не автоматически читаемым `.env`.

По умолчанию сервер слушает `http://localhost:6969`. Описание API доступно по `/docs`, схема OpenAPI — `/api-docs`. Таблицы создаются при инициализации приложения. Параметры стартового административного пользователя заданы в `main.py`; при развёртывании используйте собственные значения.

## Структура

- `services/` — маршруты авторизации, ролей, занятий, файлов и ИИ.
- `models/`, `schemas/` — модели хранения и обмена.
- `core/` — конфигурация, база и безопасность.
- `static/` — раздаваемые файлы.
- `test_main.http` — примеры запросов.

Запускайте из корня репозитория, чтобы относительные пути к базе и статическим файлам разрешались корректно. ИИ-функции требуют настроенного внешнего провайдера.
